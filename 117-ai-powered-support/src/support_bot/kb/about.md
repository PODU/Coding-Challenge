# About Coding Challenges

Coding Challenges is a platform that helps software engineers level up their
skills by building real-world applications from scratch. Each challenge guides
you through rebuilding a well-known tool — such as `wc`, Redis, a JSON parser,
or a load balancer — one small, testable step at a time.

The platform is language-agnostic: you can solve every challenge in Python,
TypeScript, Go, Java, Rust, or any language you prefer. Challenges focus on the
problem and the design, not on a particular framework.

Each challenge is broken into incremental steps. You start with a minimal
prototype and extend it step by step until you have a working clone of the real
tool, complete with tests you write yourself.
