# Challenge Catalogue

The catalogue contains dozens of challenges grouped by difficulty.

## Build your own Redis
Rebuild a Redis server that speaks the RESP protocol over TCP. You implement the
core commands such as PING, SET, GET, and EXPIRE, then add concurrency so the
server can handle many clients at once. This is an intermediate challenge.

## Build your own wc
Rebuild the Unix `wc` command-line tool. You count bytes, lines, words, and
characters, then support reading from standard input. This is a beginner
challenge and a good first project.

## Build your own JSON parser
Write a parser that validates and parses JSON text into in-memory objects. You
build a lexer and a recursive-descent parser and handle malformed input
gracefully. This is an intermediate challenge.

## Build your own load balancer
Build an HTTP load balancer that distributes incoming requests across a pool of
backend servers using round-robin scheduling, with periodic health checks to
remove unhealthy backends. This is an advanced challenge.
