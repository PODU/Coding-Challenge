# Coding Challenge #1: Build Your Own wc

Difficulty: beginner
Topics: cli, files, unicode

Build your own version of the Unix command line tool `wc` — word, line,
character and byte count.

## Steps

1. `-c`: output the number of bytes in a file.
2. `-l`: output the number of lines.
3. `-w`: output the number of words.
4. `-m`: output the number of characters (multibyte aware).
5. No flags: equivalent of `-c -l -w`.
6. Read from standard input when no file name is given.

## Example

```
> ccwc -l test.txt
  7145 test.txt
```
