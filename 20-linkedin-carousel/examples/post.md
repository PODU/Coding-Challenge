# 5 lessons from shipping side projects

A short carousel built entirely from this Markdown file.
Each `---` starts a new slide.

---

# 1. Start before you're ready

Perfect is the enemy of shipped. The first version only has to teach
you what the second version should be.

---

# 2. Constrain the scope

Pick one user, one problem, one platform. A carousel generator that does
*one* thing well beats a design suite nobody finishes.

---

<!-- bg: gradient.png opacity: 0.25 -->
# 3. Make it offline-first

Tools that work without a network are testable, fast, and dependable.
This whole PDF renders with zero HTTP calls.

---

# 4. Automate the boring parts

If you do it twice, script it. This carousel is content in, PDF out,
no manual design step.

---

# 5. Tell people

The best project nobody sees has zero impact. Ship it, post it, learn
from the replies — then do it again.
